One line, 140 characters at most: the resignation letter of something an agent
runs. The program writes that line to `/output/entry.txt` and refuses to write
anything the gate would reject.

## Run it

```sh
mkdir -p output && MAKEFUN_OUTPUT_DIR=output node main.ts
```
